## 资料管理闪退修复（2026-10-11）

- 用户报告的崩溃为 `GRDB.DatabaseQueue` 上的 Swift actor 隔离断言，定位到 `AttributeManageViewModel.observe(kind:)` 的数据库抓取闭包。品牌、分类、风格、季节、渠道共用该代码。
- GRDB 6 的 `ValueObservation.tracking` 抓取闭包未声明 Sendable，在 MainActor 方法里创建时会继承 UI 隔离；GRDB 实际在数据库队列抓取。将观察工厂移到 `nonisolated` 方法并显式使用 `@Sendable`，主 actor 仅消费结果更新界面。
- 新增可注入数据库的 ViewModel 回归，修复前复现 `unexpected signal code 5`；修复后覆盖全部五种资料的初始读取、改名、分类分组、删除及取消订阅。其余 22 处观察均在非 actor Repository 中创建，未发现相同风险。
- 同时修复更新安装后图片绝对路径失效：启动时在事务中迁移所有图片字段，只映射当前图片目录内存在的旧沙盒同名文件；保留其余字段和时间戳。共享引用按实际当前路径比较，避免旧/新字符串别名误删；目录外文件和符号链接不能读删。
- 补齐产物版本信息，报告可显示版本 `1.0`、构建 `1`。
- 快速穿搭的 PhotosPicker 标签先在主 actor 读取图片状态，只向 Sendable 标签闭包传递布尔值，消除完整编译暴露的 UI 隔离警告。
